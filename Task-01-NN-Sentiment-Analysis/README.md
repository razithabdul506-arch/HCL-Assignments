# Task 01 – Multiclass Sentiment Analysis

## Project Overview
Automated Hyperparameter Tuning and Performance Comparison of Neural Networks for Multiclass Sentiment Analysis.

## Objective
To implement and compare Neural Network, Simple RNN, LSTM, and GRU architectures for classifying sentiment into Negative, Neutral, and Positive categories.

## Technologies Used
- Python
- Google Colab
- TensorFlow / Keras
- KerasTuner
- Scikit-learn
- Matplotlib
- Seaborn

## Models Implemented
1. Neural Network (NN)
2. Simple Recurrent Neural Network (RNN)
3. Long Short-Term Memory (LSTM)
4. Gated Recurrent Unit (GRU)

Both baseline and hyperparameter-optimized models were evaluated.

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- Macro F1-score

## Files
- `NN_SENTIMENT_ANALYSIS.ipynb` – Complete implementation, training, hyperparameter tuning, and evaluation.
